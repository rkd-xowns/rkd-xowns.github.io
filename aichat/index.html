터미널 Claude Code를
채팅 창으로

The Claude Code CLI,
in a chat window

터미널의 claude를 그대로 쓰면서, 화면은 익숙한 채팅 창이에요. 쓸데없이 붙는 도구와 안내를 덜어 대화마다 드는 토큰이 적어요.

It runs your own claude CLI behind a familiar chat window, and trims unneeded tools and instructions so every message costs fewer tokens.

맥 전용 · 개발자용 · macOS 13 이상 · 무료, 오픈 소스(MIT)Mac only · For developers · macOS 13 or later · Free and open source (MIT)
맥용 내려받기Download for Mac GitHub

무엇이 좋은가요Why use it

약 60% ↓~60% less

적은 기본 토큰Fewer base tokens

질문마다 붙는 기본 몫이 데스크톱 앱 약 5만 6천에서 약 2만 2천 토큰으로 줄었어요(만든 사람 맥에서 잰 값).

The fixed overhead on every message dropped from about 56k tokens in the desktop app to about 22k (measured on the author's Mac).

폴더별 대화Chats by folder

작업 폴더 안의 프로젝트마다 대화가 묶여요. 마우스를 올리면 첫 질문 전체가 보여요.

Conversations are grouped by project folder. Hover to see the full first message.

허락 카드Permission cards

파일 수정이나 명령 실행 전에 카드로 물어봐요. '이 대화에서 계속 허락'도 돼요.

Before editing files or running commands it asks with a card. You can allow for the rest of the chat.

가벼운 대화Light chat

코딩 도구 없이 웹 검색만 쓰는 대화. 기본 약 2천 토큰이라 간단한 질문에 좋아요.

A chat with only web search and no coding tools. About 2k base tokens, good for quick questions.

명령과 스위치Commands and switches

/ 명령 목록, 모델·허락 방식 고르기, 외부 연결(MCP)·에이전트 켜고 끄기, 플러그인 관리, 사용 한도 보기.

/ command list, model and permission mode, MCP and agent switches, plugin manager and usage limits.

알림, 그리고 내 맥 안에서만Notifications, all on your Mac

일이 끝나거나 허락이 필요하면 맥 알림. 모든 것이 내 맥(127.0.0.1)에서만 돌고 대화 기록도 내 맥에만 남아요.

Mac notifications when a task finishes or needs permission. Everything runs locally (127.0.0.1) and chats stay on your Mac.

필요한 것Requirements

  • macOS 13 이상
  • Node.js (brew install node 또는 nvm)
  • Claude Code 설치 후 터미널에서 claude로 한 번 로그인. 내 Claude 계정과 요금제를 그대로 써요.
  • macOS 13 or later
  • Node.js (brew install node or nvm)
  • Claude Code installed and signed in once with claude in Terminal. It uses your own Claude account and plan.

설치 방법How to install

  1. 위 맥용 내려받기로 받은 zip을 열고, AI Code Terminal Chat.app을 응용 프로그램 폴더로 옮겨요.
  2. 처음 열 때 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 눌러요. (Apple 공증을 받지 않은 무료 앱이라 그래요.)
  3. 메뉴 AI Code Terminal Chat → 작업 폴더 바꾸기…(⌘,)에서 프로젝트들이 들어 있는 폴더를 골라요.
  4. 허락 방식은 처음엔 물어보고 함이에요. 익숙해지면 '알아서 함'으로 바꿀 수 있어요.
  1. Open the zip from Download for Mac above and move AI Code Terminal Chat.app to your Applications folder.
  2. If macOS warns you on first launch, go to System Settings → Privacy & Security and click Open Anyway. (It's a free app that isn't notarized by Apple.)
  3. Choose the folder that holds your projects from AI Code Terminal Chat → 작업 폴더 바꾸기… (Choose Work Folder, ⌘,).
  4. The permission mode starts as 물어보고 함 (ask first). You can switch to auto later.
